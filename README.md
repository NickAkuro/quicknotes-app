# QuickNotes – Note-Taking Application

## Project Description

QuickNotes is a simple and user-friendly note-taking web application built using HTML, CSS and JavaScript. It allows users to create, organize, search and delete notes under three categories: Personal, Work and Study. The application uses browser localStorage to save notes, ensuring that they remain available even after refreshing or reopening the page.

## Features

- **Add Notes:** Create new notes with a maximum of 200 characters.
- **Categories:** Organize notes into Personal, Work and Study.
- **Delete Notes:** Remove individual notes when they are no longer needed.
- **Search Notes:** Find notes quickly using keywords.
- **Input Validation:** Prevent empty notes and notes exceeding 200 characters.
- **Note Counter:** Automatically displays the total number of saved notes.
- **Date and Time:** Displays when each note was created.
- **Local Storage:** Automatically saves notes in the browser so they remain available after refreshing the page.
- **Responsive Design:** Works on desktop and mobile screens.

## Technologies Used

- HTML5 – Page structure and semantic elements.
- CSS3 – Styling, Flexbox and responsive design.
- JavaScript – Application functionality and DOM manipulation.
- Browser localStorage – Saving and retrieving notes.
- Git and GitHub – Version control and project hosting.

## How to Run the Project Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/quicknotes-app.git
   ```

2. Open the project folder:

   ```bash
   cd quicknotes-app
   ```

3. Open `index.html` in your web browser.

4. Start adding, organizing, searching and deleting your notes.

No additional software installation or external dependencies are required.
